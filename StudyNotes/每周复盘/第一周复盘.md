
## 第一周复盘

### 本周完成了什么？&#x20;

这是开始重新规划学习的第一周，先进行了个人现状整理，对自身定位了解更为清晰。为了更好地记录进步、方便复盘，我建立了 GitHub 仓库 Dash，并采用 Hexo + GitHub Pages 搭建了个人博客系统，让我的技术学习每一步都有迹可寻。同时整理了服务器部署的信息，为之后更持续的记录工作做好准备。

作为一个科研小白，为了参与到海冰预测项目中，本周我也着手于论文的入门学习。由于海冰预测与 AI 强相关，我的第一篇 AI 论文阅读选择了 Attention Is ALL You Need(Vaswani et al., 2017)，深度学习领域具有划时代意义的经典论文。通过对这篇论文的粗读和精读，我逐步建立起了论文阅读模板，在阅读论文时会有导向性的思考、回答问题。通过和大佬的交流，我也发现了在阅读过程中存在的问题：过于依赖 AI 的辅助，而节约自身的思考。在学习阶段埋下的坑，后面都会成为难以言下的苦果。后续的论文阅读，要更投入、更真切。

想要搞清楚自己在海冰预测项目中具体能够承担的工作，本周我和负责人确认了论文目前的状态，综合考量后初步确定承担英文摘要初稿和论文 LaTeX 排版两项工作。作为对这个领域的扫盲，我学习了一些海冰预测任务的基本背景，好歹能知道任务方向大概是个什么样的。

为了丰富简历，也为了提升实力、快速上手深度学习，我也在尝试相关的入门竞赛和练习赛。经过对阿里天池、百度飞桨、Kaggle 等多个竞赛平台的调研，我也选定了一个深度学习入门赛：Kaggle 上最经典、最有名的入门竞赛 [<u>Titanic - Machine Learning from Disaster</u>](https://www.kaggle.com/c/titanic/overview?_gl=1*1e6npo3*_ga*MTc0MDMxMTM3LjE3Nzg5ODY3Nzk.*_ga_T7QHS60L4Q*czE3Nzg5OTI0NDQkbzIkZzEkdDE3Nzg5OTI4MzgkajUyJGwwJGgw)。这个入门比赛资源很丰富，适合做为入门练习。

本周还尝试做出了一塌糊涂乏善可陈的简历初稿，朋友作为面试官跟我展开了人生第一场模拟面试。我什么也没答出来，但并非一无所获。具体的收获也写在了面试复盘。

### 哪些任务没完成？ 没完成的原因是什么？

第一天计划的 Codex 使用笔记没有写。虽然已经用 Codex 做了一些工作，但是还没有明确的好的使用经验和提升策略，只是一种感叹于它很强大的初体验。后面用顺手了再补上一些使用体会。

论文阅读笔记01和 AI 术语表的改进还是不够好。第一轮粗读后，AI 代替大脑，大段文字代替思考，产出的东西非常糟糕，效果很差。后面稍做修改，还是不够满意。或许真正建立自己的论文阅读体系是一个积累的过程。

### 哪件事最有价值？ 哪件事最浪费时间？

个人复盘、博客搭建以及 GitHub 系统记录学习仓库的建立最有价值。这让我养成了持续学习、记录产出的习惯。没有最浪费时间的事，但是最费时间的还是读论文。

### 下周最应该推进什么？

准备一个能写进简历的 Agent 项目，调研实习岗位并优化简历。
