## 第二周复盘

#### Agent/AIGC Demo 是否完成？

本周完成了 Paper-Reading-Agent 项目的最小demo，这是一个本地优先的论文阅读 Agent 原型，后续完善方向是：把关键词检索替换成 embedding 向量检索、接入真实 LLM、增加 PDF 解析、引入 SQLite 本地存储。

#### 项目最有价值的地方是什么？

目前这个 demo 虽然粗糙，但是帮助我快速把 Agent 应用的工程链路搭起来，而不是停留在一些八股的了解。以及在从零开始逐步搭建的过程中，一些细节问题也让我学习到了很多，尤其是做功能分层，不同模块分别设计，各司其职，也让我对 Agent 项目的结构有了更好理解。

#### 项目最薄弱的地方是什么？

目前是关键词检索效果差。在替换成向量检索前，可能还需要尝试优化一下现有的关键词检索算法。

#### 简历是否比第一版更贴近目标岗位？

贴近多了。第一版简历上只有一个自动化测试的项目，跟 Agent 开发几乎沾不上边，而且技术栈等的描述也根据 Agent 岗位 和我做的小项目做了优化。

#### 岗位调研后发现自己缺什么？

缺一个真正成熟的 Agent 项目以及后端基础八股。简历上的项目应该最好是一个纯 Agent 项目搭配一个传统后端结合 AI 的项目，这样方便面试官考察后端工程基础和新技术知识。&#x20;

#### 论文阅读是否能和项目或海冰协作结合？

很遗憾的是，由于一些活动、任务的占用，本周的论文阅读任务直到写下这篇复盘的时候还没有完成。预计阅读 EMFormer: Efficient Multi-Scale Transformer for Accumulative Context Weather Forecasting，这个在 Transformer 基础上进行优化的模型在长期天气预报上表现很好，海冰预测也需要解决长期预测的各种问题，这个模型可以给我们带来长期预测的启发。
