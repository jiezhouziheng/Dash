- Agent 项目：把现有 Paper-Reading-Agent 写成“RAG + Tool Calling + 文档解析 + 本地存储 + 可视化交互”的完整项目，而不是只写“调用大模型 API”。
- 工程化：补 FastAPI、Docker、日志、异常处理、接口文档、单元测试、README、Demo 截图。
- RAG 能力：补文本切分、Embedding、向量库、重排、评测指标、问答质量对比。
- Agent 能力：补 Planning、Memory、Tools、Function Calling、LangChain/LangGraph/Dify/Coze 至少一种实操。
- 投递材料：准备 1 页中文简历、项目 README、3 分钟 Demo 视频或截图、GitHub 链接。
