**Paper-Reading-Agent｜本地论文阅读 Agent 原型** 

Python / FastAPI / Pydantic / pytest / JavaScript / RAG Workflow 

- 设计并实现面向科研论文阅读的本地 AI Agent 原型，支持用户输入论文标题、摘要和 Markdown 正文，自动完成论文结构解析、文本分块、结构化分析结果生成、阅读笔记落盘和基于论文片段的最小问答闭环。 
- 搭建清晰的 Agent 后端分层架构，将 API 路由、Pydantic Schema、业务编排、Markdown 解析、chunking、检索、阅读笔记渲染、模型调用边界和本地存储拆分为独立模块，便于后续接入真实 LLM、PDF 解析和向量检索。
- 使用 FastAPI 提供 /api/papers/analyze 和 /api/papers/{paper_id}/ask 接口，通过 Pydantic 进行请求校验和响应建模，支持自动生成唯一 paper_id，并将 paper.md、analysis.json、chunks.json、reading_note.md 等运行产物持久化到本地目录。 
- 实现 Markdown 标题解析与段落级文本分块，将论文正文转换为可检索 chunks；实现关键词检索器，根据用户问题匹配相关片段，并返回 chunk id、章节标题、原文片段和命中分数，保证问答结果具备基础可追溯性。 
- 封装 LLMClient 作为模型调用边界，预留论文总结、术语表提取和学习计划生成接口；当前版本优先完成本地数据流、模块边界和测试体系，为后续接入 OpenAI-compatible API 和语义级 RAG 打基础。 
- 编写 pytest 测试覆盖 API、服务层、Markdown 解析、文本分块、关键词检索和阅读笔记渲染，提升项目在后续重构和能力扩展时的稳定性。 
- 实现原生 HTML/CSS/JavaScript 前端页面，支持后端健康检查、论文分析提交、结构化结果展示、当前 paper_id 维护和论文问答交互，完成 Agent 工作流的端到端验证。
