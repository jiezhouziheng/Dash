## 第三轮项目定位

**这个项目解决什么真实问题？**

Paper-Reading-Agent 是一个面向科研论文阅读的本地 AI Agent 原型项目，主要解决论文阅读费时费力，效率低下的问题。也是为了更好地辅助我快速粗读论文，在做一个简历项目的同时又能够切实帮助到自己的论文学习。

**目标用户是谁？**

所有有着快速读论文需求的用户。很多论文读起来很困难，借助 Agent 可以快速过一遍论文，建立总体认知，提高学习效率。

**输入是什么？**

目前是论文标题、摘要以及 markdown 正文，以及用户针对论文内容提出的自然语言问题，还有像输出偏好等用户个性化的约束。

**输出是什么？**

结构化阅读笔记、术语表、学习规划、问答结果。目前本地论文记忆没落地的情况下，学习规划暂时只能根据用户提供背景描述来生成。

**项目最核心的 3 个亮点是什么？**

1. 固定后端输入和输出 schema，LLM 输出会被校验成约定结构，避免不稳定文本直接污染系统。

2. 增加文本分块 chunks，把长篇幅的论文切分成可检索片段。

3. Citation 的返回。Agent/LLM 应用很容易产生幻觉，返回 citation 可以告诉用户答案来自哪些论文片段，至少具备基础可追溯性。接入 LLM 时，也可以要求模型只能基于 citations 回答。

**哪些功能是当前版本明确不做的？**

完整 PDF 解析、高难度的向量检索、复杂用户系统。
