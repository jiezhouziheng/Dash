
## Paper-Reading-Agent简历描述草稿

**技术版**

**Paper-Reading-Agent｜本地论文阅读 Agent 原型** &#x20;

`Python / FastAPI / Pydantic / pytest / Markdown Parser / Retrieval`

* 基于 FastAPI 构建论文阅读 Agent 后端，提供 `/api/papers/analyze` 与 `/api/papers/{paper_id}/ask` 接口，支持论文分析、结构化结果返回和基于当前 `paper_id` 的问答流程。

* 使用 Pydantic 设计请求/响应与内部数据模型，覆盖 `PaperAnalysisResult`、`TextChunk`、`MarkdownSection`、`AnswerCitation` 等 Schema，并通过字段校验保证摘要和正文不能同时为空。

* 实现 `PaperService` 作为业务编排层，串联输入归一化、唯一 `paper_id` 生成、Markdown 原文保存、章节解析、文本分块、阅读笔记渲染、JSON 落盘和问答检索流程。

* 实现 Markdown parser，解析 `#` 到 `######` 标题并生成章节结构；实现段落级 chunking，将论文正文切分为最大约 800 字符的可检索文本片段。

* 实现关键词检索模块 `KeywordRetriever`，从用户问题中提取中英文 token，对 chunks 进行命中计分排序，并返回 chunk id、章节标题、原文片段和 score，形成可追溯问答的基础 citation。

* 封装 `LLMClient` 作为模型调用边界，预留论文总结、术语提取和学习计划生成接口，方便后续替换为 OpenAI-compatible API 或其他大模型服务。

* 编写 pytest 测试覆盖 API、服务层、Markdown 解析、chunking、关键词检索、阅读笔记渲染等核心路径，提升后续接入真实 LLM、向量检索和 PDF 解析时的重构稳定性。

**场景版**

**Paper-Reading-Agent｜面向科研论文阅读的 AI Agent 原型** &#x20;

`Python / FastAPI / Pydantic / JavaScript / pytest`

* 设计并实现面向科研论文阅读的本地 Agent MVP，帮助用户从论文标题、摘要和 Markdown 正文中快速整理论文结构、核心信息、术语表、学习计划和阅读笔记。

* 围绕“论文阅读效率提升”设计完整工作流：用户提交论文内容后，系统自动生成唯一论文 ID，保存原文，解析章节结构，切分可检索片段，并输出 `analysis.json`、`chunks.json` 和 `reading_note.md`。

* 支持基于当前论文的最小可追溯问答：用户围绕论文提问后，系统从论文片段中检索相关内容，返回答案、引用片段、章节标题和命中分数，降低无依据回答的风险。

* 将论文分析结果结构化为研究问题、方法、贡献、局限、术语表和学习计划等模块，方便用户将论文内容转化为复习资料、技术笔记或后续学习任务。

* 实现轻量前端页面，支持后端健康检查、论文分析提交、分析结果展示、当前 `paper_id` 维护和论文问答交互，完成从输入到问答的端到端验证。

* 当前版本优先完成本地数据流、可追溯问答和模块边界，后续可扩展 PDF 解析、真实 LLM 总结、向量检索、多论文管理和阅读历史记录。
